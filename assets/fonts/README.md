# Karla

Fonte incluída para os títulos e rótulos dos modelos vetoriais, com suporte a acentos e uso offline no Android, iOS e web.

- Origem: https://github.com/google/fonts/tree/main/ofl/karla
- Arquivo original: `Karla[wght].ttf`, salvo como `Karla.ttf`.
- Licença: SIL Open Font License 1.1, incluída em `Karla-OFL.txt`.
